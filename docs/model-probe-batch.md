# 有界多样本工具协议评估

`scripts/model_probe_batch.py` 顺序重复单次工具协议探测，每个样本重新生成内存回执，
不共享对话。它衡量同一配置下的协议通过率，不能代表 Easel 端到端任务质量或其他模型的表现。
前置说明和凭据设置见 [模型工具协议探测](model-tool-probe.md)。

```bash
python scripts/model_probe_batch.py --live --model YOUR_MODEL --samples 3 --total-timeout 180
```

默认 3 个样本，允许 1–20 个，每个样本最多 2 次请求；默认每次最多 256 个输出 token，
`--max-tokens` 可设为 1–1024。整个批次默认 180 秒，最多 600 秒；单样本最多 60 秒且不得
超过批次剩余时间。没有重试、并发请求、自动模型切换或真实工具副作用。
HTTP 错误（含限流、鉴权失败及重定向）、传输错误或超时会停止后续样本；协议不合格记为失败样本，
继续下一个独立样本。客户端截止不保证远端停止计算或计费，请求数限制也不是货币预算。

输出只包含聚合 JSON，不含模型名、地址、凭据、提示、原始响应或回执：

- `samples_attempted` / `samples_not_run` 明确区分已尝试和未运行样本。
- `pass_rate_attempted` 仅以已尝试样本为分母；必须同时查看 `complete` 和状态分布。
  中途停止后剩余样本不算成功或失败。样本很少时不能据此推断稳定性或模型排名。
- 延迟包含所有已尝试样本（包括失败），报告中位数和 nearest-rank P95；小样本 P95 通常就是最大值。
- token 用量只在所有已尝试请求均有完整合法用量时汇总，否则为 `null`；这不是服务账单核验。
  未运行样本不产生用量；`cost` 始终为 `null`，不推测单价或免费额度。
- 退出码 0：全部计划样本通过；1：存在失败或未运行样本；2：配置错误。

需要在报告之外记录模型版本、服务配置和代码提交，才能进行有意义的复现或对比。当前不提供
多任务业务评测、价格计算或统计显著性结论。CI 仅运行离线 HTTP fixture，不读取真实凭据。
